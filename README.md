## GitHub Pages
Upload all files and the `assets` folder to the root of your GitHub repository. Keep the folder and filenames unchanged. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The feedback form currently opens the visitor's email application; it does not store feedback online.
